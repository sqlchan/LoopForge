# 公共适配范围

本仓库包含自托管平台与 LoopForge Local。详细的源码同步记录由维护者私下保管，不随公共源码分发。部署密钥、生产数据与私有基础设施均不包含在内。

| 领域 | 公共行为 |
| --- | --- |
| 引擎、持久化、runner 协议、门禁、制品、协同 | 上游实现与测试 |
| Web 工作区与导航 | 上游 master 布局 |
| 身份 | 本地密码账号；显式开通账号 |
| 管理员 | 无内置员工白名单；通过显式授权/配置产生 |
| 仓库托管 | GitHub 引用规范化、Issue 导入、PR 发现/合并/状态刷新 |
| MCP | 显式安装；公共 GitHub 入口；按 actor 作用域绑定令牌 |
| 目录 | 公共后端/前端/产品/缺陷修复定义；真实的脚本审批演示 |
| 模型默认值 | CLI 默认与运维配置的模型列表；Main Bot 与 SOP 角色可选 CodeBuddy/Codex/Claude，凭据按 actor 作用域绑定 |
| Git 作者身份 | 本地账号名与不可投递的 LoopForge 邮箱；不推断企业归属 |
| 语言 | 带公共 UI 文案的翻译机制/词典；中文/英文偏好 |
| 主题 | 上游明/暗样式；偏好在首次绘制前应用并持久化 |
| LoopForge Local | `local/` 下的内置工作流、宿主集成、安装器与测试；`docs/local/` 下的指南；仓库根目录的项目策略与历史 |

旧的组织专属跟踪系统与认证协议代码作为可选兼容代码保留，并附带示例端点。其 Web 入口（外部跟踪系统同步字段、TAPD 导入/推送）默认保持隐藏。内置的公共托管 API 适配器对接 github.com。GitHub Enterprise、GitLab、Gitea 及其他 Git 托管可通过 [Git SSH](deployment.md#通过-ssh-访问-git-仓库) 绑定，用于克隆与推送；托管 API 操作需要各自的适配器或 MCP。公共默认值绝不会安装企业 MCP server，也不会联系企业身份/市场服务。

仅含源码的 master 不带其部署环境的数据库种子内容。公共 SOP 定义因此是显式的公共目录数据，并不表示包含私有生产项目或提示词。行为与执行和 master 共享；运维资产、凭据与私有集成属于部署数据。

翻译层排除代码编辑器、日志、Markdown、contenteditable 区域，以及标记了 `data-i18n-skip` 的用户文本。英文字典可以独立扩展。新增的上游界面文案需要在同步时做翻译评审。
