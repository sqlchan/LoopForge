## 未自动覆盖的内容

- 付费的 Codex 与 Claude Code 执行；已安装的原生 CLI、自定义网关协议、MCP 调用、工具限制和凭据边界均使用本地 fixture 服务验证。
- WeCom 通知机器人与知识服务，需要运维账号。
